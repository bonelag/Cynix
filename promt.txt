Bạn là chuyên gia Android/Java.  
Tôi có một đoạn code quản lý menu game (Back menu + Sub menu Advanced).  
Nhiệm vụ:
1. Đọc code, cho tôi biết thứ tự hiện tại của các tính năng trong Back menu và Sub menu (Advanced) trong file app/src/main/java/com/limelight/GameMenu.java
2. Sửa code để sắp xếp lại menu theo thứ tự sau:

Back menu (menu chính):
1. Disconnect (Ngắt kết nối game stream)
2. Hiển thị gamepad (Toggle Virtual Model / Virtual Controller)
3. Hiển thị bàn phím đầy đủ (Toggle Virtual Keyboard Model)
4. Hiển thị phím đặc biệt (Send Keys)
5. Chọn chế độ chuột (Select Mouse Mode)
6. Bật Pan/Zoom (Enable/Disable Zoom Mode)
7. Xoay màn hình (Rotate Screen)
8. Hiển thị bàn phím mềm (Toggle Keyboard)
9. Tùy chọn nâng cao (Advanced)
10. Thoát phiên (Quit Session)
11. Hủy (Cancel)

Sub menu Advanced:
1. Hiển thị lớp phủ hiệu suất (Toggle HUD)
2. Thay đổi độ nhạy cảm ứng (Switch Touch Sensitivity Model)
3. Gửi nội dung clipboard (Upload Clipboard)
4. Lấy nội dung clipboard (Fetch Clipboard)
5. Lệnh máy chủ (Server Cmd)
6. Mở trình Task Manager (Task Manager = Ctrl+Shift+Esc)
7. Gửi phím đặc biệt (Send Keys)
8. Hủy (Cancel)

Yêu cầu khi sửa code:
- Giữ nguyên logic gốc (if/else, check context, allowChangeMouseMode...).
- Chỉ thay đổi **thứ tự addItem()** trong back menu và submenu.
- Không làm mất các điều kiện hiển thị (ví dụ: chỉ hiển thị Rotate nếu context = game).
- Xuất code sau khi chỉnh sửa, không giải thích thêm.

# PATCH
Xem trong source control: (bỏ qua file promt.txt)
- ghi toàn bộ các thay đổi (thêm file/sửa code/xóa code,...) toàn bộ vào trong change.patch trong thư mục patch
- tạo patch.md để nói rõ về những gì đã thêm/sửa để các AI sau này chỉ cần đọc là có thể áp dụng thay đổi này cho các bản cập nhật sau
- nếu là file mới hoàn toàn hãy thêm chúng vào thư mục patch/file và ghi chú rõ vào md để AI biết cách dùng chúng
* LƯU Ý: Nếu các file trên (change.patch và patch.md) đã được tạo và đã có nội dung trước đó, thì cập nhật thêm vào cuối file thay vì tạo file mới và làm mất đi các thay đổi trong bản cũ đã có

# Multi Layout gamepad

* Hãy đọc và nắm rõ dự án
- bây giờ hãy tập trung vào tính năng virtual gamepad, hãy tìm hiểu kỹ


* Vấn đề hiện tại là: setting layout cho gamepad là chung cho tất cả app/game, do là điều khiển gamepad ảo trên điện thoại nên layout này là thực sự cần thiết để chơi game/làm việc, nhưng việc chỉ có thể sử dụng 1 layout duy nhất, chỉ dùng được cho đúng một app, nếu sử dụng app/game khác lại phải đổi layout rất phiền phức, bây giờ hãy lên kế hoạch triển khai tính năng Multi Layouts, để thêm/sửa/xóa layout tùy ý cho từng app
# Các yêu cầu:
- Không được làm mất logic của các tính năng khác của app, chỉ tập trung duy nhất vào LAYOUT GAMEPAD
- Code sạch/ không bug/ không lỗi build
# Kết quả dự kiến:
- Trong floatmenu (back menu), nút "Hiển thị gamepad" hiện tại sẽ trở thành nút "Lựa chọn gamepad layout", ấn vào sẽ mở ra sub menu để lựa chọn gamepad, gồm các tính năng thêm/xóa/sửa layout hiện có (không làm mất đi biểu tượng setting để sửa layout khi đang sử dụng 1 layout bất kỳ - hiện tại đang dùng cái đó là chính để sửa layout )
- Lưu trữ setting các layout trong bộ nhớ riêng của app, đảm bảo tính nhất quán và nhanh chóng
